# 社群自我介紹

根據品牌定位、核心受眾與平台需求，建立品牌一句話、名稱欄與社群自我介紹。

## 安裝

下載本儲存庫，將完整資料夾命名為 `profile-bio-writer`，放入個人 Codex skills 目錄 `~/.codex/skills/`。保留 SKILL.md、agents、assets 及其他隨附資料夾。

## 使用範例

使用 $profile-bio-writer，幫我建立 IG 社群帳號自我介紹。

## 檔案

- `SKILL.md`：技能流程與規則。
- `agents/openai.yaml`：顯示名稱與預設提示詞。
- `assets/icon.svg`：技能圖示。
## 共用品牌資料

啟動時會先讀取使用者指定的品牌檔、目前對話已確認的同品牌檔案，或目前內容專案根目錄的 `brand-profile.md`，沿用已知品牌、服務與受眾。找不到檔案時仍可繼續，只詢問必要資訊；多品牌無法判斷時先確認。

只有明確要求「更新品牌資料」或「存到 brand-profile.md」才保存，寫入前先讀取並備份既有檔案，完成後回報位置。「從零開始」或「不沿用品牌資料」會跳過自動讀取。

`brand-profile.md` 是個人內容專案的資料，不是技能安裝檔。本儲存庫不包含你的私人品牌資料，保存也不等於授權發布到 GitHub。

範例：

> 使用這個技能，沿用目前專案的品牌資料。

> 將這次確認的服務與受眾更新到品牌資料。
